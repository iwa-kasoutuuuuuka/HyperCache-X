## 1. 概要
HyperCache X (HCX) は、HDD (Hard Disk Drive) の低速な I/O パフォーマンスを、
高速な SSD (Solid State Drive) をキャッシュ層として利用することで劇的に向上させる、ハイブリッド・ストレージ加速エンジンである。

### プロジェクト目標
- 読み込み速度の飛躍的向上（AIベースのパターンスキャンによる動的昇格）
- 書き込み速度の加速（SSDへのライトバック・リダイレクト）
- キャッシュ状態の永続化（PC再起動後も加速状態を維持）

---

## 2. システムアーキテクチャ
HCX は、特権レベルでのディスク操作を行う「カーネルモード・ドライバ」と、
インテリジェンスな制御を行う「ユーザーモード・エンジン」の 2 層構造で構成される。

### 構成要素
1. **HCX.Driver (カーネルモード)**
   - ファイルシステム・ミニフィルタドライバ。
   - すべての I/O 要求 (IRP) をインターセプトし、キャッシュマップに基づき SSD へリダイレクトする。
2. **HCX.Core (ユーザーモード・エンジン)**
   - I/O パターンの分析、キャッシュデータの物理転送、メタデータの永続化を担当。
3. **HCX.App (ユーザーインターフェース)**
   - WPF ベースの現代的なパフォーマンス・ダッシュボード。

---

## 3. 機能仕様

### 3.1 読み込み加速 (Read Acceleration)
- **AI 昇格エンジン**: アクセス履歴をリアルタイムにスキャンし、
- ヒット頻度の高いブロックを「AI Scoring」に基づき SSD へコピー。
- **リダイレクト**: HDD への読み込み要求が発生した際、
- ドライバが SSD 上の対応するオフセットからデータを高速に返し、HDD への物理アクセスをバイパスする。

### 3.2 ライトバック・キャッシュ (Write-Back)
- **高速書き込み**: 書き込み要求を SSD 側のバッファへ即座にリダイレクト。
- **Dirty フラグ管理**: SSD にのみ書き込まれ、HDD と同期していないブロックを `IsDirty` フラグで追跡。
- **バックグラウンド・同期**: 低負荷時にエンジンが SSD から HDD へデータを順次書き戻す。

### 3.3 キャッシュ永続化 (Persistence)
- **メタデータ管理**: `cache_metadata.dat` に LBA (論理ブロックアドレス) と SSD オフセット、および属性を保存。
- **状態復旧**: キャッシュエンジンの開始時に、前回のマップと `IsDirty` 状態を瞬時に復元。

## 4. データ構造定義

### 4.1 キャッシュ・エントリー (C/C++ & C# 共通)
```c
#pragma pack(push, 1)
typedef struct _CACHE_ENTRY {
    ULONGLONG SourceLba;  // HDD 上の論理アドレス
    ULONGLONG SsdOffset;  // SSD 上 service物理オフセット
    BOOLEAN IsValid;      // キャッシュが有効か
    BOOLEAN IsDirty;      // HDD への書き戻しが必要か
} CACHE_ENTRY;
#pragma pack(pop)
```

### 4.2 IOCTL インターフェース
通信用制御コード (DeviceIoControl):
- `0x800`: エンジン開始
- `0x802`: ターゲットディスク設定
- `0x803`: マッピング更新 (ユーザーモード → カーネル)
- `0x805`: SSD パスの設定
- `0x806`: マップ情報の取得 (カーネル → ユーザーモード、Dirty 監視用)

## 5. UI/UX 設計
### 5.1 プレミアム・ダッシュボード
- **テーマ**: ダークモード、グラスモルフィズム、ネオンアクセント。
- **ビジュアライザー**:
  - **32x8 ヒートマップ**: 全ブロックのアクセス状況を 256 の発光マスで表現。
  - **リアルタイム・スループット**: 現在の I/O 速度を大きなデジタル数値で表示。
  - **エンジンステータス**: ONLINE (Green) / OFFLINE (Red) インジケーター。

---

## 6. 安全性と整合性
- **管理者権限の強制**: RAW ディスク操作を伴うため、マニフェストにより管理者実行を必須化。
- **SyncAll シーケンス**: アプリ停止時に、すべての Dirty ブロックを HDD へ強制的にフラッシュする。
- **エラーハンドリング**: ドライバまたは SSD の障害を検知した場合、
- 即座に HDD へのパススルーへ切り替え、データの欠損を防止。
